How it works

ε-closure

ε-closure(S) = S plus every state reachable by zero or more ε-moves. BFS with a visited set, so cycles and self-loops terminate.

Subset construction

D0 = ε-closure({q0}); δD(S,a) = ε-closure(⋃ δN(q,a) for q ∈ S). New subsets are queued until none remain; ∅ is the dead state.

Acceptance

A DFA state is accepting iff S ∩ F ≠ ∅. ε is never consumed from the input string; it is only followed through closures.
